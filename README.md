# Boxieace Engineering Portfolio

A Vite + React portfolio for robotics, 3D printing, CAD, and student engineering projects.

## Local development

```bash
npm install
npm run dev
```

## Deploy

This repository deploys to GitHub Pages with the workflow in `.github/workflows/deploy.yml`.
Pushes to `main` build the React app and publish the `dist` folder to `https://boxieace.github.io`.
