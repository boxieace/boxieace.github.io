# Boxieace Robotics & Fabrication Portfolio

A Vite + React portfolio for robotics, FRC Team NOVA 11270, 3D printing, CNC/engraving research, and hardware/software engineering projects.

## Local development

```bash
npm install
npm run dev
```

## Deploy

This repository deploys to GitHub Pages with the workflow in `.github/workflows/deploy.yml`.
Pushes to `main` build the React app and publish the `dist` folder to `https://boxieace.github.io`.
